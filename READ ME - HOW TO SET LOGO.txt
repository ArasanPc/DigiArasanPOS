DIGI ARASAN POS — App Icon / Shortcut Logo Setup
==================================================

WHAT WAS ADDED
---------------
- favicon.ico + icons/ folder (13 sizes generated from your DIGI ARASAN logo)
- manifest.json (tells Chrome the app name + which icon to use)
- index.html updated with <link> tags pointing to the icons + manifest

This is what makes Chrome show your red "DIGI ARASAN" logo (instead of a
blank page screenshot) when you use "Install App" / "Create Shortcut".

IMPORTANT: KEEP THE FOLDER STRUCTURE TOGETHER
-----------------------------------------------
Do NOT copy just index.html on its own. Keep this exact structure:

    digiarasan-pos/
    ├── index.html
    ├── manifest.json
    ├── favicon.ico
    └── icons/
        ├── icon-16.png
        ├── icon-32.png

If any icon file is missing or moved, Chrome will fall back to a generic
page icon.

WHY IT MIGHT STILL NOT SHOW THE LOGO: file:// LIMITATION
-----------------------------------------------------------
If you just double-click index.html and open it directly from your computer
(a "file://" address in the address bar), Chrome usually CANNOT install it
as a proper PWA and often can't load manifest.json at all — browsers block
that for local files. In that case "Create Shortcut" only creates a normal
desktop shortcut and may use a generic icon.

TO GET THE LOGO TO SHOW ON THE SHORTCUT, HOST IT (even locally) INSTEAD OF
OPENING THE FILE DIRECTLY. Easiest options:

OPTION A — Quick local server (no internet needed)
1. Install Python (most PCs already have it).
2. Open the "digiarasan-pos" folder.
3. Right-click inside the folder > "Open in Terminal" (or open Command
   Prompt/PowerShell and "cd" into the folder).
4. Run:
       python -m http.server 8000
5. In Chrome, go to:
       http://localhost:8000/
6. Click the 3-dot menu (⋮) > "Save and share" (or "Cast, save, and
   share") > "Install page as app" (or the install icon ⊕ in the address
   bar) > Install.
   This creates a proper app shortcut with your logo.

OPTION B — Upload to free hosting
Upload the whole "digiarasan-pos" folder to a free static host such as:
- GitHub Pages
- Netlify Drop (netlify.com/drop — just drag & drop the folder)
- Vercel
Then open the live https:// link in Chrome and use "Install App" from the
address bar (⊕ icon) or the 3-dot menu. The logo will appear correctly.

OPTION C — Just want a desktop shortcut icon (not a real app install)
If you only need a normal Windows/Mac shortcut icon (not Chrome's PWA
install), right-click your desktop shortcut > Properties > Change Icon >
browse to icons/icon-256.png (Windows needs a .ico — you can rename/convert
favicon.ico for this, or use icon-256.png if your OS allows PNG icons).

SUMMARY
-------
- The icons + manifest are ready and linked in index.html.
- For the logo to actually appear on an installed shortcut, the page must
  be opened via http:// or https:// (a real or local server), not by
  double-clicking the file directly.
